Задание 1

Приложение разделено на три микрофронтенда, каждый микрофронтент отражает свою предметную область.

Первый микрофронтенд: Authentication - отвчечает за логирование и регистрацию. Компоненты - InfoTooltip, Login, Register.
Второй микрофронтенд: Card - зона ответственности ограничена карточкой с фотогрфией, загрука, удаление, лайки. Компоненты - AddPlace, Card, Image.
Третий микрофронтенд: Profile - отображение информации о пользователе, редактирование фотографии пользователя и его данных. Компоненты - EditAvatar, EditProfile, Profile.

Использовалась стратегия проектирования - вертикальеая нарезка, приложение поделилось на предметные области. Каждый домен (микрофронтенд) обрабатывает только то, что зависит от его функций.
Данный подход был выбран тк исходное приложение легко выделить границы ограниченного контекста, непересекающиеся бизнес-функции.
